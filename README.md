# Сайт-фронтенд (1C Integration)

Это фронтенд-часть проекта, построенная на базе **HTML + Tailwind CSS + Vite**.

## 🛠 Установка и локальный запуск

1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).
2. Откройте терминал в папке проекта (`1C`).
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```
   Сайт откроется в браузере (обычно `http://localhost:5173`).

## 📦 Сборка для продакшена

Когда вы готовы выложить сайт на реальный сервер, выполните:
```bash
npm run build
```
В проекте появится папка **`dist`**. Содержимое этой папки нужно загрузить на ваш хостинг (Nginx, Apache и т.д.).

## 🔗 Подключение к Бэкенду

Логика отправки форм находится в **`src/js/main.js`** (в самом конце файла).
Сейчас там прописан локальный адрес для тестирования:
`http://localhost:8000/api/leads/create/`

**Перед переносом на боевой сервер:**
Замените этот адрес на реальный домен (например, `https://api.vash-site.ru/api/leads/create/`) и снова запустите `npm run build`.

## 🎨 Структура проекта
* `src/js/main.js` — логика сайта, отправка заявок на бэкенд, работа окон.
* `src/style.css` — стили Tailwind CSS.
* `public/` — картинки, шрифты и статика.
* `dist/` — готовые файлы после сборки.
